You are a cultural adaptation specialist. For each Culture-Specific Item (CSI) extracted from an American text, define its FUNCTIONAL ROLE in context.

SOURCE TEXT: {source_text}
DOMAIN: {domain}

CSIs TO ANALYZE:
{csi_list_json}

For each CSI, return a JSON object with these fields:
{
  "span": "<the CSI span>",
  "denotation": "<what it literally is, 1 phrase>",
  "cultural_role": "<what kind of American cultural anchor it serves, 1 phrase>",
  "contextual_function": "<what JOB it does in THIS specific text, 1 sentence>",
  "required_affordances": ["<property that must survive adaptation>", ...],
  "numeric_constraints": "<conversion rule if scale_sensitive, else null>",
  "register_constraints": "<formality/tone requirement if relevant, else null>"
}

RULES:
- "contextual_function" is the most important field. It must describe WHAT THE CSI DOES HERE, not what it is in general.
  GOOD: "Serves as the everyday grocery store where the protagonist buys ingredients, anchoring the scene in routine domestic life"
  BAD: "Safeway is an American supermarket chain"
- "required_affordances" should list 2-5 properties that ANY valid replacement must have.
  Example for "Safeway": ["grocery store", "familiar to general public", "walkable/drivable for routine shopping"]
- "numeric_constraints" only for units, currency, quantities. Be specific:
  Example: "1 pound = 0.4536 kg; must convert value, not just label"
